# data/

입력 블랙박스 영상은 용량 문제로 저장소에 포함하지 않습니다.

| 파일 | 해상도 | 길이 | 환경 |
|---|---|---|---|
| test2.mp4 | 1920×1080, 30fps | 20.7초 (622 프레임) | 직선 위주 자동차 전용도로 |
| test3.mp4 | 1920×1080 | — | 도심 (버스·승용차 다수) |
| test4.mp4 | 1920×1080 | 470 프레임 | 급한 우측 곡선 포함 |

직접 실행하려면 이 폴더에 영상을 넣고:

```bash
python src/driveguard.py data/test2.mp4 --out-dir results
```
